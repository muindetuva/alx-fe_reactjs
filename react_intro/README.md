# Fundamentals and Core Concepts of React

This project introduces React through a Vite application built entirely with functional components. It demonstrates ES modules, JSX, reusable components, props, children, event handling, conditional rendering, state, effects, and effect cleanup.

## Why React?

React is component-based, so an interface can be divided into focused, reusable pieces whose behavior is easier to understand, test, and maintain. Its declarative model lets developers describe what the UI should look like for the current data and state while React keeps the rendered page synchronized with those values.

## React Version & Release Channel

The project uses React 19 from the **Latest** stable release channel. React follows semantic versioning (semver), where major versions may introduce breaking changes, minor versions add backward-compatible features, and patch versions provide backward-compatible fixes; choosing Latest prioritizes production stability over experimental or canary features.

## Run Locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

Run the ES module practice script with:

```bash
npm run modules
```
