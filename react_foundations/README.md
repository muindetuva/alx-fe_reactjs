# Styling, States, Rendering, Routes and Hooks

This Vite React project demonstrates inline and modular styling, state-driven search, declarative routing, controlled forms, nested routes, and a guarded custom theme Hook. Every component is functional and uses modern React and React Router APIs.

## Inline Styles vs CSS Modules

An inline style object keeps small one-off declarations close to a component, but it becomes harder to maintain as a design grows and cannot directly express selectors such as `:hover`. CSS Modules keep styles locally scoped while supporting complete CSS behavior, making the modular profile card easier to extend and maintain.

## Run Locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
