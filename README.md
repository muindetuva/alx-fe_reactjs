# ALX Frontend React Projects

This repository contains React projects and exercises completed as part of the ALX frontend curriculum.

## Projects

- `react_intro`: Fundamentals and core concepts of React using Vite, JSX, props, events, and Hooks.
- `react_foundations`: Styling approaches, state-driven rendering, modern routing, and reusable context Hooks.
- `react_hooks`: Reusable custom Hooks, hook composition, persistence, fetching, pagination, debouncing, and Vitest tests.
- `react_styling`: Bootstrap and Tailwind comparisons, responsive utility styling, custom design tokens, theming, and accessible dialog primitives.
- `react_state`: Zustand state management with slices, middleware, persisted todos, settings, filtering, and store tests.
- `advanced_state`: Context scaling patterns and Redux Toolkit state for a themed asynchronous shopping experience.
